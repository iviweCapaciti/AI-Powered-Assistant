# Neptune 🌊
### Your AI Teammate for Work

Neptune is an AI-powered workplace productivity hub that helps teams draft emails, plan tasks, summarize meetings, and research topics — all in one place.

Built for modern teams who want to save time and ship faster.

## ✨ Features

- **AI Copilot Chat**
  Ask anything. Get instant drafts, summaries, plans, and research.
- **Smart Templates**
 1-click workflows for Emails, Meeting Notes, Weekly Planning, and Research.
- **Team Collaboration**
  Shared workspaces, shared chat history, and shared prompt templates.
- **Integrations**
  Connect Gmail, Slack, Google Calendar, and Notion in one click.
- **Analytics Dashboard**
  Track AI credits used and time saved by your team.
- **Enterprise Ready**
  Role-based access, SOC2 compliant, end-to-end encryption.

## 🚀 Tech Stack

- **Frontend**: React, TailwindCSS, Framer Motion
- **Backend**: Node.js, Express
- **AI**: OpenAI / Anthropic API
- **Auth**: Clerk / Google OAuth
- **Database**: PostgreSQL + Prisma
- **Payments**: Stripe
- **Hosting**: Vercel
